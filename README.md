### Currently building → [Flashpoint.ai](https://flashpoint.ai)

I run engineering at **Natural Language Labs**, where we're building Flashpoint: professional-grade market research, built AI-native. Quantitative, qualitative and behavioral methods in one study you can field in an afternoon instead of weeks.

### About

A decade of building: I've started companies, been an early engineer helping others scale, and led engineering teams. These days I'm the person teams bring in when the hard part isn't the code, but knowing what to build and making it feel right.

On the side I run **[IXC Commons](https://raghavarora.com/ixc-commons)**, a builder community in Chandigarh — small rooms, laptops open, everyone leaves with something that runs.
